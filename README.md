# Ping Virtual

Calculateur de **points virtuels FFTT** (tennis de table), installable sur le téléphone (PWA, fonctionne hors ligne).

- Points virtuels = points mensuels + matchs joués depuis la dernière situation mensuelle
- Grille officielle FFTT (écart / victoire ou défaite normale ou anormale) × coefficient de la compétition
- Plusieurs joueurs, simulateur de match, objectif de classement, export / import

Les données restent sur le téléphone (stockage du navigateur). Les points officiels sont ceux publiés par la FFTT.
